# React Style

- Functional components only. No class components.
- Hooks stay at the top level only, and custom hooks start with `use`.
- Prefer interfaces for object-shaped props and avoid `any`.
- Test user-visible behavior with React Testing Library and accessible queries.
- Use one styling strategy per project. Do not mix CSS Modules and Tailwind unless the repo already does.
- Read `.claude/conventions/react-style.md` for the full guide.
