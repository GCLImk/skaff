# Vue 3 Style

- Composition API only. No Options API.
- Use `<script setup lang="ts">` and keep composables prefixed with `use`.
- Prefer typed props and emits. Avoid `any`.
- Test user-visible behavior with Vue Testing Library and accessible queries.
- Use one styling strategy per project.
- Read `.claude/conventions/vue3-style.md` for the full guide.
